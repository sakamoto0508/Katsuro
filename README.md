# Katsuro

- 戦闘シーン：`Assets/Katsuro/Scenes/GameScene.unity`
- 修練シーン：`Assets/Katsuro/Scenes/TutorialScene.unity`

- 調整用データ：`Assets/Katsuro/Data`
- 外部アセット：`Assets/ThirdParty`
- Blender制作元・参考資料：`Source/Art`

各フォルダの用途と配置ルールは [フォルダ構成ガイド](Docs/ProjectStructure.md) を参照してください。
